Anyone landing on this repo should see first that it's a fork, what keeps it current, and how to install its build. A GitHub note block is the very first thing in `README.md`, above upstream's `# herdr` heading: it says this is a personal fork of herdr (linked) that updates itself with autofork (linked to https://autofork.com), that its changes are described in plain words in `.autofork/` (linked) and go back on top on each herdr release, and that it publishes its own builds for macOS and Linux (x86_64 and arm64). It gives the one-line install command, which runs upstream's own installer from this fork, `https://raw.githubusercontent.com/AVGVSTVS96/herdr/main/distribution/install.sh`, says the installer checks the download against this fork's sha256 manifest, and that `herdr update --handoff` keeps it current from this fork's releases. It ends with "Everything below is the upstream README, unchanged."

Keep the note first in the file. Nothing else in the README changes: if upstream edits the top of its README, keep their content as they wrote it, right below the note. Keep what the note says true to how this fork works: if it stops publishing builds, or the install command or update path changes, change the note with it.

This patch is done once the fork stops publishing its own builds, or when the note moves to a file of the fork's own outside upstream's tree.
